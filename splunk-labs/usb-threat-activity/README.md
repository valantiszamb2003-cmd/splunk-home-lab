A Splunk dashboard that monitors USB device activity and detects insider‑threat behavior. It correlates logs with user identity, job role, and endpoint IP to highlight high‑risk events such as USB mass‑storage usage and suspicious file‑copy operations.

Key Features
User & device correlation (full_name, job_title, ip_address).

Detection of USB Mass Storage devices.

Identification of file‑copy spikes (data exfiltration).

Clear separation of normal vs suspicious USB activity.

Trend visualization of USB usage over time.
