Transactions by JSESSIONID and Client IP (Splunk Dashboard)
This project demonstrates a Splunk dashboard used to analyze web application transaction behavior across user sessions.
The dataset is synthetic and designed for educational and portfolio purposes, showcasing how Splunk can be used for session analytics, behavioral monitoring, and event correlation.

Overview
The dashboard aggregates transaction data by:

JSESSIONID (unique user session)

clientip (client IP address)

duration (session duration)

eventcount (number of events per session)

action list (addtocart, purchase, view, remove, changequantity)
