Splunk Partner KPI Dashboard
This project showcases a simple Splunk dashboard used to analyze event performance across telecom partners.
The dataset is synthetic and generated for demonstration purposes, focusing on how Splunk can be used to calculate KPIs such as success rates, failure rates, and total event counts.

Overview
The dashboard aggregates events by partner and computes:

Total events

Successful events (responseCode = 200)

Failed events (responseCode > 200)

Success percentage

Failure percentage
